## Blockers found and fixed

### 1. `claude --slash` is not a real CLI flag

**File:** `src/atlas/orchestrator.py:SubprocessStageRunner.run()`

The original code called:
```
["claude", "--slash", plugin_cmd, "--context", tasks_md, "--task", ctx.task]
```
`--slash` does not exist in the Claude CLI. The correct form for non-interactive plugin invocation is:
```
["claude", "-p", "/<cmd> <task>", "--no-session-persistence", "--add-dir", ...]
```

**Fix applied:** Replaced the invocation. Added `build_prompt()` helper in `plugin_resolver.py` to handle both slash-command form (`"/cmd task"`) and raw-prompt form (`"RAW:..."`) for stages with no slash command.

---

### 2. Plugin commands are workspace-scoped; `cwd` matters

**File:** `src/atlas/orchestrator.py:SubprocessStageRunner.run()`

Plugin slash-commands (`DEV-ESSENTIALS:code-review`, `DEV-ESSENTIALS:dev-docs-be`) are installed as `Scope: local` in the atlas workspace. Running `claude` with `cwd` = the Flask target repo causes "Unknown skill" errors.

**Fix applied:** Added `_find_atlas_root()` which walks up from `__file__` to find the main repo's `.git` directory (skipping any worktree `.git` file). Claude is invoked with `cwd=atlas_root`. The Flask repo and worktree are passed via `--add-dir` so the plugin can access them.

```python
def _find_atlas_root() -> Path:
    candidate = Path(__file__).resolve()
    for parent in candidate.parents:
        git = parent / ".git"
        if git.is_dir():
            return parent
    return Path(__file__).resolve().parent.parent.parent
```

### 3. Plugin command mappings were wrong

**File:** `src/atlas/plugin_resolver.py`

The original mappings used bare command names that don't match the installed plugin structure. The DEV-ESSENTIALS plugin has:
- **Skills** (bare name): `consult-experts`, `lateral-thinking`, `git-workflow`
- **Commands** (namespaced): `DEV-ESSENTIALS:dev-docs-be`, `DEV-ESSENTIALS:code-review`
- **Agents** (not slash-commands): `plan-reviewer`, `documentation-architect`

`code-gen-agent` has no matching plugin — falls back to a raw prompt.

**Fix applied:** Updated `PLUGIN_COMMANDS` and introduced `RAW:` prefix for raw-prompt stages:

```python
PLUGIN_COMMANDS = {
    "consult-experts:research": "consult-experts",   # skill, bare name
    "consult-experts:pm":       "consult-experts",
    "consult-experts:tech-lead":"consult-experts",
    "dev-docs-be":              "DEV-ESSENTIALS:dev-docs-be",   # namespaced command
    "plan-reviewer":            "consult-experts",              # agent → routed via skill
    "code-gen-agent":           "RAW:Implement the following task by writing and committing code:",
    "code-review":              "DEV-ESSENTIALS:code-review",   # namespaced command
}
```

### 4. `PlumbIO.close_run()` called `__exit__` on the wrong object

**File:** `src/atlas/plumb_io.py`

Plumb's context manager pattern:
```python
ctx = plumb_run(...)          # _RunFactory — has __exit__
handle = ctx.__enter__()      # RunHandle — does NOT have __exit__
```

The original code stored `self._run_handle = ctx.__enter__()` and called `self._run_handle.__exit__(...)`. `RunHandle` has no `__exit__`, so spans were buffered in memory but never flushed to SQLite.

**Fix applied:** Store both objects:
```python
self._run_ctx = plumb_run(task_id=task, kind="online")
self._run_handle = self._run_ctx.__enter__()
```
And call `self._run_ctx.__exit__(None, None, None)` in `close_run()`.

Also fixed the error-case call: was `__exit__(type(exc), exc, None)` for success path with `exc=None`, giving `__exit__(NoneType, None, None)` instead of `__exit__(None, None, None)`.

### 5. Post-commit hook used bare `python` — wrong interpreter

**File:** `src/atlas/post_commit_hook.py`

The hook script installed by `atlas hook install` was:
```sh
#!/bin/sh
python -m atlas.post_commit_hook
```

On systems with pyenv, bare `python` resolves to a Python that doesn't have atlas installed (e.g., 3.14 from pyenv), causing `ModuleNotFoundError`.

**Fix applied:** Hook now embeds the full path of the Python that ran `atlas hook install`:
```python
def _hook_script() -> str:
    import sys
    python = sys.executable
    return f"#!/bin/sh\n# Installed by atlas hook install\n{python} -m atlas.post_commit_hook\n"
```
